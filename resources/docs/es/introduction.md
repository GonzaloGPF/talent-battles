## ¿Qué es TalentBattles? {#introduction-what-is}

**Talent Battles** nace como un proyecto personal con la intención de crear una aplicación para artistas
y aprendices del mundo de la producción musical y el diseño digital.

El principal propósito de esta web es el de ofrecer un lugar que pueda ayudar a los artistas a progresar 
mientras compiten y se divierten haciendo lo que más les gusta.

**Talent Battles** pretende ser un lugar de fácil acceso para todos, también para visitantes y buscadores de talento.
Es un lugar ideal para navegar y buscar creaciones, conseguir inspiración o para encontrar nuevos contactos
y oportunidades de negocio.

Esta aplicación intenta diferenciarse del resto ofreciendo funcionalidades únicas y originales,
como son las batallas y torneos de creaciones. 
También intenta facilitar las búsquedas de las creaciones de sus artistas,
además de ofrecerles estadísticas interesantes sobre su actividad y desempeño.
