In this section ([Tracks](/admin/tracks) or [Designs](/admin/designs)) you will have the list of all your Creations.

## Management {#creations-admin}
You will be able to carry out a typical administration of each of your Creations (View, Edit, Delete, Download).

You can also **start Battles** or **list** a Creation from this list, by expanding any row in the table.

## Find Battle {#creations-search-battle}
By expanding a row of the list, you will have access to some extra options, among them, the one of **Search Battle**.
You can only Search Battle if the Creation in question is not participating in a Battle.

If the system does not find any previously open Battles, it will create one and keep the Battle open until another User
search for a Battle.

> [!NOTE]
> You can cancel the Battle as long as it is in the **Open** state

When the Battle starts, it will go into the **In Progress** state. You will not be able to modify the Creation or cancel the Battle until it ends.

## Sell Creation {#creations-sell}
Within the Details of each Creation, you can also indicate if you want to sell the Creation, by clicking on the button
**To sell**.

> [!NOTE]
> Remember that to sell a Creation you must upload the version **without watermark**

If the Creation is already for sale, you can cancel the Sale so that it is no longer available for purchase by other Users.

> [!WARNING]
> If the Creation has been Sold exclusively, you will not be able to make modifications
