## Upload Track {#upload-track}
In order to upload a Track, you must press the **Upload** button, at the bottom right of the application.
Fill in, at a minimum, all the required fields, marked with an asterisk (*).

Next, we briefly detail each of them:
- Type: Select the type of track:
    - Beat: If your track is an Instrumental, designed to sing along or as a demonstration of your skills
    - Sample: When it is a small fragment of sound, such as a series of chords or a melody with a single instrument
    - Song: If you have created a complete product combining voices, beats and samples
- Name: The name that other Users will see
- Bpm: Indicates what the Tempo is. If you left it empty, the system will try to guess it
- Tags: They are a series of words that can help to search for the creation
- Color: It will define the color of the audio shape of your Track. It is also the color that will be used if you do a [Promote](promote.md)
- Album: If you have created an Album, here you can link it
- Can Challenge: Check this option if you want to allow other Users to create Battles against your creation
- Genre: You can specify to which Genre or Genres it belongs
- Key: Indicates the main scale in which it is composed
- Instrument: If you see fit, you can also indicate which is the main instrument of the composition
- Description: A text with extra information. You can express what you intend to convey, what aspects you would highlight, why you have created it, etc.
- Battle: If you check this option, your Creation will immediately search for a compatible [Battle](battles.md). If it doesn't exist, it will create one and wait for an Opponent.

> [!CAUTION]
> Unverified emails will only be able to upload up to three tracks

## Upload Design {#upload-design}
In the same way you can upload a Track, you can also upload a Design, the procedure is the same, except
that you will have to select the **Design** tab, after clicking the **Upload** button.

Next, we will detail only the specific fields of a Design:
- Aspect Ratio: You can indicate the Dimensions of your Creation.
- Style: If you see fit, you can choose a specific style from the list.

> [!CAUTION]
> Unverified emails will only be able to upload up to three designs

## Upload File {#upload-file}
Upload the **Image** and the **Audio** (in case it is a Track) of your Creation. Both files will be publicly displayed to all Users and visitors to the platform.
Make sure you upload only what you want to share and expose with the world. Normally, here you should upload files **With Watermark**.

> [!CAUTION]
> If you select the **Auto Mark** option, you must upload the file **Without Watermark**

### Watermarks
Although the system can 'Auto Mark' your creations, you will get the best quality if you mark it yourself, so you will know
where to put your Watermark better.

If you wish, you can use our Watermarks:
- Tracks: [watermark.mp3](/storage/watermark.mp3)
- Designs: [watermark.webp](/storage/watermark.webp)

## To sell {#upload-battle}
You may have noticed that, in both forms, there is a special section for [Sell](buy_sell.md).
These are a series of options that will allow you to offer your Creation as a product that other Users can buy.

Once you check this option, new fields will appear:
- Price: Indicates what the base price will be. The system will apply taxes and commissions as extra amounts when a User wants to buy it.
- Exclusive: This option will prevent multiple Users from buying it, that is, at the time you make the sale, no one else will be able to buy this Creation
- Auto Mark: So you don't have to upload two different files, you can ask **Talent Battles** to generate a file with a Watermark from the File without marks
- File: This is the file that buyers can download. This file will remain secret with restricted access.
