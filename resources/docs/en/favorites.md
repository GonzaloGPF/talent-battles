# Favorites

---
Your [Favorites](/admin/battles) is the section where lives all the
**Favorites** that you mark in **Talent Battles**.

- [Favorites Lists](#favorites-lists)
- [Favorites Details](#favorites-details)

## Favorites Lists {#favorites-lists}
You can organize your Favorites by creating **Favorites Lists**, by this way, when you mark something as Favorite,
you will be able to save it in a certain list (for example 'I want to buy' or 'The Best').

This way you can organize your own content so that, in the future, you can consult it more comfortably.

## Favorites Details {#favorites-details}
Each Favorite will display information about the content you've bookmarked. You can delete or modify it at any time.
the **Favorites List** to which it belongs.
